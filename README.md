# # CodeAlpha Student Grade Tracker

## CodeAlpha Java Programming Internship - Task 1

A console-based Java application developed as part of the CodeAlpha Java Programming Internship.

## Features

- Input and manage student names and grades
- Store student data using ArrayList
- Calculate the average grade
- Find the highest grade
- Find the lowest grade
- Display a summary report of all students
- Validate grades between 0 and 100

## Technologies Used

- Java
- ArrayList
- Object-Oriented Programming
- Scanner

## How the Program Works

The program accepts the number of students and their names and grades from the user. It then calculates the average, highest, and lowest grades and displays all student records in a summary report.

## How to Run

Compile the program:

```bash
javac StudentGradeTracker.java
